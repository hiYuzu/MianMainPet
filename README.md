# 绵绵 AI 桌宠 v2.0.4

面向 Windows 10/11 的 .NET 10 WPF 私人 AI 桌宠。v2.0.4 的目标不是功能堆叠，而是一只安静陪伴、自然互动、偶尔带来惊喜的白粉侧视小羊。

## 开发环境

- Windows 10 22H2 或 Windows 11（x64）
- .NET SDK 10.0.302 或兼容的 10.0.x SDK
- VS Code
- C# Dev Kit 扩展

## 私人构建前的唯一配置

打开 `MianMianPet\Services\InternalAiConfig.cs`，只替换这一项：

```csharp
internal const string ApiKey = "PASTE_YOUR_VERIFIED_DEEPSEEK_API_KEY_HERE";
```

将其换成 v0.1 已验证的 DeepSeek API Key。Base URL、模型、输出长度、温度、上下文窗口和 2 秒气泡时间都集中在同一个内部配置类中，设置页面不会显示这些内容。

> 桌面程序中的内置 API Key 无法真正保密。请仅向自己或可信任对象分发包含真实 Key 的构建，不要将源代码或二进制公开发布。公开分发前应改用自建后端代理。

当前交付包没有包含真实 API Key，因为此前源码和需求附件均未提供该密钥；除此之外不需要首次运行配置。

## 内置体验配置

主动陪伴、闲置睡眠、昼夜分段和人设化失败回复集中在：

```text
MianMianPet\Configuration\PetExperienceConfig.cs
```

昼夜效果会根据电脑本地时间自动切换，不需要用户设置。

## 构建与运行

用 VS Code 打开包含 `MianMianPet.slnx` 的根目录，然后运行：

```powershell
.\build.ps1
dotnet run --project .\MianMianPet\MianMianPet.csproj
```

单击小羊会打开独立、可激活的输入窗口：

- `Enter`：发送
- `Shift + Enter`：换行
- `Esc`：关闭；如果 IME 正在组合，则先交给输入法处理
- 回复中点击停止按钮：取消当前请求

## v2.0.4 用户可见变化

- 系统托盘右键菜单增加“关于”，可打开与小羊风格统一的版本信息窗口。
- 关于窗口显示当前运行程序的真实程序集版本，今后版本升级会自动同步，不依赖界面硬编码。
- 修复极端视觉异常或通知异常导致发送状态无法复位的问题。
- SSE 流读取改为完全异步等待，停止按钮和请求超时可以及时中断等待中的读取。
- AI 回复期间点击小羊不再打开输入窗口、隐藏正在生成的回复或清空临时输入。
- 输入窗口按 `Alt+F4` 时改为安全隐藏，之后仍可正常再次打开和退出程序。
- 桌宠位置读取或保存失败时只记录日志并使用安全位置，不再导致应用退出。
- 设置保存增加串行保护，避免设置页与托盘同时保存时争用同一个临时文件。
- 只有确认属于 SQLite 数据损坏的错误才会备份并重建数据库；瞬时占用或磁盘错误不会清空活动数据库。
- 修复睡眠切换恰逢眨眼时可能睁眼睡觉，以及启动时先闪现在默认位置再跳动的问题。
- 修复请求失败或取消后，未完成的用户消息进入后续模型上下文的问题；成功的一问一答现在使用同一事务保存。
- 启动时会自动识别旧版本遗留的孤立用户消息并排除出上下文，不删除已有的正常聊天记录。
- 修复开机启动切换失败时注册表、内存设置和界面勾选可能不一致的问题。
- 修复损坏数据库恢复后缺少 WAL 模式和字段约束的问题。
- 修复环境动画 Storyboard 资源实例复用风险，并移除没有实际用途的 `--autostart` 启动参数。
- 发送窗口与回复气泡统一改为柔白云朵造型，使用多层云瓣、轻粉描边、柔和阴影和小云点尾巴。
- AI 请求超时、断网或服务异常时不再显示技术错误，改为从内置的人设化回复中随机选择一句。
- 增加无需设置的主动陪伴：首次 8～12 分钟，之后 50～60 分钟，深夜 90～120 分钟；电脑长时间无人操作、输入、对话或设置期间不会打扰。
- 保留单击回弹和打开输入框，增加闲置睡眠与自然唤醒动作。
- 增加自动晨间、白天、黄昏和夜间氛围，按本地时间切换柔光、太阳、月亮和星点。
- 连续 10 秒没有与小羊交互时，草地、漂浮云朵、柔光和闪烁星光会渐渐浮现；点击、拖动、悬停、右键、输入或气泡交互后立即淡出并重新计时。
- 连续 90 秒没有交互时，小羊会闭眼呼吸、浮现睡眠符号；再次互动时自然醒来。
- 星光使用独立前景层：参考原图的暖金四角星、白紫小星和蜜桃粉光点会错峰发光、旋转并缩放，不再被白色羊毛遮挡。
- 绵绵右键菜单只保留“设置”和“退出”。
- 设置页只保留小羊名称、称呼、开机启动和总在最前，桌宠固定使用 150×150 小尺寸。
- 新用户默认称呼为“小静”。修改小羊名称或称呼时会重置模型的活动上下文起点，旧 SQLite 记录仍然保留。
- DeepSeek 连接和生成参数改为内部固定配置。
- 输入区域从 WPF `Popup` 改为真正的独立 `InputWindow`，明确激活并聚焦真实 `TextBox`。
- IME 通过组合开始、更新、完成事件跟踪；候选状态下的 Enter 不会误发送拼音。
- IME 开始组合时会立即隐藏输入提示文字，避免临时拼音与 placeholder 重叠。
- 回复气泡默认完整展开，不再包含滚动条或展开/收起按钮。
- 回复完成后停留 2 秒；悬停暂停，离开后重新计时。
- EXE、系统托盘和设置窗口统一使用小羊头像图标；托盘右键菜单不再包含唤醒和隐藏/显示。
- 删除所有普通用户清空聊天记录的入口，SQLite 历史机制保持不变。

## 设置迁移

旧版 `settings.json` 可直接保留。`System.Text.Json` 会忽略旧配置中的 `ApiKey`、`BaseUrl`、`Model`、`MaxTokens`、`Temperature`、`BubbleDuration` 等未知字段；缺失的新字段会采用默认值。SQLite 数据库不迁移、不清空。

运行数据仍保存在 `%LocalAppData%\MianMianPet`：

```text
mianmian.db
settings.json
logs\
cache\
```

日志不记录聊天正文、请求体、Authorization Header 或 API Key。

## 发布

```powershell
.\publish.ps1
```

输出位于 `publish\win-x64`，使用 self-contained x64 单文件发布。未启用裁剪，避免影响 WPF XAML 和 SQLite 运行时行为。

## 目录结构

```text
MianMianPet/
├── Animation/       # 角色状态与动画调度
├── Configuration/   # 内置陪伴、昼夜与失败回复参数
├── Infrastructure/  # 单实例、系统活动、屏幕定位、命令和转换器
├── Models/          # 用户设置、消息与人设模型
├── Resources/       # 内嵌人设提示词
├── Services/        # 内部 AI 配置、API、SQLite、托盘、启动项
├── ViewModels/      # 桌宠和设置状态
├── Views/           # 桌宠、侧视小羊、独立输入窗口、气泡、设置页
└── Properties/      # win-x64 发布配置
```

版本变化见 `CHANGELOG.md`。
